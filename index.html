GrundlagenThe basics

Was macht Gampi genau?What exactly does Gampi do?

Gampi ist ein kleines Windows-Programm, das das Bild deines Monitors anpasst: Gamma, Helligkeit, Kontrast und Sättigung. Die Einstellungen speicherst du als Preset pro Spiel, und Gampi schaltet sie beim Spielstart automatisch ein und danach wieder aus.Gampi is a small Windows program that adjusts your monitor's picture: gamma, brightness, contrast and saturation. You save the settings as a preset per game, and Gampi switches them on automatically when the game starts and off again afterwards.

Was ist der Unterschied zwischen Gamma und Helligkeit?What's the difference between gamma and brightness?

Helligkeit macht alle Bereiche gleich viel heller – das Bild wirkt dadurch schnell blass. Gamma hellt vor allem die dunklen und mittleren Töne auf, helle Bereiche bleiben fast gleich. Der Schatten-Boost von Gampi geht noch weiter und hebt nur die dunkelsten Stellen an.Brightness makes all areas equally lighter – which quickly makes the picture look pale. Gamma mainly lifts the dark and middle tones, while bright areas stay almost the same. Gampi's shadow boost goes further and lifts only the darkest spots.

Was ist ein Preset?What is a preset?

Eine gespeicherte Kombination aus allen Einstellungen, zum Beispiel „Nacht“ oder „Labs“. Pro Spiel kannst du beliebig viele anlegen und per Hotkey oder Klick wechseln.A saved combination of all settings, for example “Night” or “Labs”. You can create as many per game as you like and switch by hotkey or click.

Was ist ein ICC-Profil – brauche ich das?What is an ICC profile – do I need one?

Ein ICC-Profil ist eine Datei, die beschreibt, wie dein Monitor Farben darstellt – oft vom Hersteller oder aus einer Kalibrierung. Das ist optional: Die meisten kommen ohne aus. Wer eins hat, kann es einem Preset zuordnen.An ICC profile is a file that describes how your monitor displays colors – often from the manufacturer or a calibration. It's optional: most people don't need one. If you have one, you can assign it to a preset.

Ist Gampi nur für Spiele?Is Gampi only for games?

Nein. Die Einstellungen wirken auf alles, was dein Monitor zeigt. Du kannst statt eines Spiels jedes Programm anlegen, etwa einen Videoplayer oder den Browser.No. The settings apply to everything your monitor shows. Instead of a game, you can add any program, such as a video player or the browser.

Was kostet Gampi?What does Gampi cost?

Nichts. Kein Abo, kein Konto, keine Werbung.Nothing. No subscription, no account, no ads.

Sicherheit und DatenschutzSafety and privacy

Greift Gampi ins Spiel ein?Does Gampi touch the game?

Nein. Gampi ändert nur die Bildausgabe deiner Grafikkarte – so wie die Farbeinstellungen im Treiber oder am Monitor. Es läuft kein Code im Spiel, Gampi liest keinen Spielspeicher und zeichnet kein Overlay.No. Gampi only changes your graphics card's display output – like the color settings in the driver or on the monitor. No code runs in the game, Gampi reads no game memory and draws no overlay.

Windows warnt beim ersten Start – ist das gefährlich?Windows shows a warning on first start – is that dangerous?

Windows zeigt diese Warnung bei neuen Programmen, die noch wenig verbreitet sind. Über „Weitere Informationen“ → „Trotzdem ausführen“ startet Gampi. Lade Gampi nur über diese Seite oder GitHub herunter.Windows shows this warning for new programs that aren't widely used yet. Click “More info” → “Run anyway” to start Gampi. Only download Gampi from this site or GitHub.

Sammelt Gampi Daten?Does Gampi collect data?

Nein. Gampi baut keine Internetverbindung auf. Deine Presets liegen nur auf deinem PC.No. Gampi doesn't connect to the internet. Your presets stay on your PC.

Bleibt mein Bild verstellt, wenn ich Gampi beende?Does my picture stay changed when I quit Gampi?

Nein. Beim Beenden, beim Abmelden und beim nächsten Start setzt Gampi alles auf Standard zurück. Sollte doch einmal etwas hängen bleiben: Gampi einfach neu starten.No. When you quit, sign out and on the next start, Gampi resets everything to default. If something ever does stick: simply restart Gampi.

Einrichtung und NutzungSetup and use

Installer oder portable Version – was soll ich nehmen?Installer or portable version – which should I pick?

Der Installer legt einen Startmenü-Eintrag an, bietet Autostart an und lässt sich über die Windows-Einstellungen deinstallieren. Die portable Version ist eine einzelne Datei ohne Installation – praktisch zum Ausprobieren. Beide können dasselbe.The installer adds a Start menu entry, offers autostart and can be uninstalled via Windows settings. The portable version is a single file without installation – handy for trying it out. Both do the same.

Brauche ich Administratorrechte?Do I need administrator rights?

Nein. Nur in zwei Sonderfällen kann Windows einmal nachfragen: wenn du das Windows-Gamma-Limit aufhebst und wenn du zum ersten Mal ein ICC-Profil hinterlegst.No. Windows may ask once in two special cases: when you remove the Windows gamma limit and when you assign an ICC profile for the first time.

Muss Gampi die ganze Zeit laufen?Does Gampi have to run all the time?

Für das automatische Umschalten ja. Gampi läuft dann unauffällig im Infobereich der Taskleiste und braucht kaum Leistung. Mit Autostart startet es direkt beim Anmelden.For automatic switching, yes. Gampi then runs quietly in the taskbar's notification area and uses hardly any resources. With autostart, it starts right when you sign in.

Woher weiß Gampi, welches Spiel läuft?How does Gampi know which game is running?

Du hinterlegst beim Spiel die EXE-Datei, zum Beispiel „EscapeFromTarkov.exe“ – oder wählst sie aus den laufenden Programmen aus. Gampi prüft alle zwei Sekunden nur die Namen der laufenden Programme.You set the game's EXE file, for example “EscapeFromTarkov.exe” – or pick it from the running programs. Every two seconds, Gampi checks only the names of running programs.

Wie finde ich die richtigen Einstellungen?How do I find the right settings?

Am einfachsten mit einer Vorlage: Night Ops für dunkle Spiele, Clarity für ein klareres Bild, Vivid für mehr Farbe. Danach nach Geschmack nachregeln – jede Änderung wirkt sofort. Gampi kann auch einen Screenshot deines Spiels analysieren und Werte vorschlagen. Ein Doppelklick setzt einen Regler zurück.The easiest way is a template: Night Ops for dark games, Clarity for a clearer picture, Vivid for more color. Then adjust to taste – every change takes effect instantly. Gampi can also analyze a screenshot of your game and suggest values. A double-click resets a slider.

Kann ich Presets mit Freunden teilen?Can I share presets with friends?

Ja. Exportiere ein Preset als Datei; deine Freunde ziehen sie einfach ins Gampi-Fenster. Hotkeys und ICC-Profile bleiben dabei persönlich und werden nicht mitgegeben.Yes. Export a preset as a file; your friends simply drag it into the Gampi window. Hotkeys and ICC profiles stay personal and aren't included.

Wie deinstalliere ich Gampi?How do I uninstall Gampi?

Installer-Version: über Windows-Einstellungen → Apps. Portable Version: Datei löschen. Deine Presets liegen unter %AppData%\Gampi – den Ordner kannst du ebenfalls löschen.Installer version: via Windows Settings → Apps. Portable version: delete the file. Your presets are stored in %AppData%\Gampi – you can delete that folder too.

Technik und KompatibilitätTechnical and compatibility

Kostet Gampi FPS oder erhöht es die Latenz?Does Gampi cost FPS or add latency?

Nein. Die Grafikkarte wendet die Einstellung über eine eingebaute Tabelle an, wenn sie das Bild an den Monitor schickt. Es gibt kein Overlay und keinen Filter, der jedes Bild nachbearbeitet.No. The graphics card applies the setting through a built-in table when it sends the picture to the monitor. There's no overlay and no filter processing every frame.

Welche Grafikkarten und Windows-Versionen werden unterstützt?Which graphics cards and Windows versions are supported?

Windows 10 und 11 (64 Bit) mit jeder Grafikkarte. Nur die Sättigung braucht eine AMD- oder NVIDIA-Karte. Zusätzliche Software wie .NET musst du nicht installieren.Windows 10 and 11 (64-bit) with any graphics card. Only saturation needs an AMD or NVIDIA card. You don't need to install extra software such as .NET.

Funktioniert das im Vollbild?Does it work in fullscreen?

Ja. Manche Spiele setzen das Bild beim Vollbild-Wechsel oder nach Alt+Tab zurück – Gampi merkt das und stellt dein Preset sofort wieder her.Yes. Some games reset the picture when switching to fullscreen or after Alt+Tab – Gampi notices and restores your preset right away.

Ich habe mehrere Monitore – was passiert?I have several monitors – what happens?

Gampi wirkt auf den Hauptbildschirm. Welcher das ist, legst du in Windows unter Einstellungen → System → Anzeige fest. Die anderen Monitore bleiben unverändert.Gampi works on the primary display. You choose which one that is in Windows under Settings → System → Display. The other monitors stay unchanged.

Funktioniert das mit HDR?Does it work with HDR?

Teilweise. Ist HDR an, ignoriert Windows die Gamma-Einstellungen; die Sättigung funktioniert weiterhin. Gampi weist dich darauf hin. HDR schaltest du mit Win + Alt + B ein und aus.Partly. With HDR on, Windows ignores the gamma settings; saturation still works. Gampi lets you know. Toggle HDR with Win + Alt + B.

Warum sehe ich den Effekt nicht auf Screenshots?Why can't I see the effect in screenshots?

Die Grafikkarte wendet ihn erst bei der Ausgabe an den Monitor an – Screenshots und Aufnahmen entstehen vorher. Mit der Vorher/Nachher-Funktion und der LUT für OBS kannst du ihn trotzdem zeigen.The graphics card applies it only when sending the picture to the monitor – screenshots and recordings are taken before that. With the before/after feature and the LUT for OBS you can still show it.

Gampi meldet, dass Windows die Einstellung ablehnt?Gampi says Windows rejected the setting?

Windows blockiert sehr starke Anpassungen standardmäßig. Klicke in Gampi unten auf „Windows-Gamma-Limit aufheben“ und bestätige einmal mit Administratorrechten. Falls es danach noch nicht klappt, einmal ab- und wieder anmelden.Windows blocks very strong adjustments by default. Click “Remove Windows gamma limit” at the bottom of Gampi and confirm once with administrator rights. If it still doesn't work, sign out and back in once.
