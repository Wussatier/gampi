Kein Eingriff ins SpielNo tampering with the game

Gampi arbeitet ausschließlich mit Windows- und Treiberfunktionen – so wie die Farbeinstellungen deiner Grafikkarte. Gampi only uses Windows and driver functions – just like your graphics card's color settings.

Was Gampi nutztWhat Gampi uses

  • Die Windows-Gamma-Kurve der GrafikausgabeThe Windows gamma curve of the display output
  • AMD- bzw. NVIDIA-Treiber für die SättigungThe AMD or NVIDIA driver for saturation

Was Gampi nicht tutWhat Gampi doesn't do

  • Kein Code im Spielprozess, kein Einschleusen von DLLsNo code in the game process, no DLL injection
  • Kein Lesen oder Schreiben von SpielspeicherNo reading or writing game memory
  • Kein Overlay über dem SpielNo overlay on top of the game
  • Keine Tastatur- oder Maus-Hooks, keine TreiberinstallationNo keyboard or mouse hooks, no driver installation

Hinweis: Wir können nicht für jedes Anti-Cheat-System garantieren. Bei Turnieren und in Spielen mit eigenen Regeln zu Bildeinstellungen gelten deren Regeln. Note: We can't give guarantees for every anti-cheat system. At tournaments and in games with their own rules on display settings, those rules apply.

FAQ

Ist Gampi wirklich kostenlos?Is Gampi really free?

Ja. Kein Konto, keine Werbung in der App, keine Datensammlung.Yes. No account, no ads in the app, no data collection.

Windows warnt beim Start („Der Computer wurde geschützt“)?Windows shows a warning (“Windows protected your PC”)?

Das zeigt Windows bei neuen Programmen, die noch wenig verbreitet sind. Über „Weitere Informationen“ → „Trotzdem ausführen“ startet Gampi.Windows shows this for new programs that aren't widely used yet. Click “More info” → “Run anyway” to start Gampi.

Warum sehe ich den Effekt nicht auf Screenshots?Why can't I see the effect in screenshots?

Die Grafikkarte wendet die Einstellung erst bei der Ausgabe an den Monitor an – Screenshots und Aufnahmen entstehen vorher. Für Bilder und Videos hat Gampi deshalb eine Vorher/Nachher-Funktion und exportiert eine LUT für OBS.The graphics card applies the setting only when sending the picture to the monitor – screenshots and recordings are taken before that. That's why Gampi has a before/after feature for images and exports a LUT for OBS.

Funktioniert das mit HDR?Does it work with HDR?

Unter HDR ignoriert Windows die Gamma-Kurve. Gampi weist darauf hin – die Sättigung funktioniert weiterhin. HDR lässt sich mit Win + Alt + B umschalten.Windows ignores the gamma curve while HDR is on. Gampi tells you so – saturation still works. Toggle HDR with Win + Alt + B.

Welche Grafikkarten werden unterstützt?Which graphics cards are supported?

Gamma, Kontrast und Schatten-Boost funktionieren mit jeder Grafikkarte. Die Sättigung nutzt den AMD- oder NVIDIA-Treiber.Gamma, contrast and shadow boost work with any graphics card. Saturation uses the AMD or NVIDIA driver.

Bleibt mein Bild verstellt, wenn ich Gampi beende?Does my picture stay changed when I quit Gampi?

Nein. Beim Beenden, Abmelden und beim nächsten Start setzt Gampi alles auf Standard zurück.No. When you quit, sign out and on the next start, Gampi resets everything to default.
